원더보이 몬스터랜드 MSX V9968 패처 0.9.40

아케이드 롬(한글 패치 v0.21·v0.10, 일본판 wbml·wbmld, 영문 wbmlb 중 하나, 어느 것인지 자동으로 알아봄)을 넣으면 MSX 터보 R + V9968 용 롬을 만듭니다. 파일은 브라우저 안에서만 처리되고 어디에도 올라가지 않습니다.

아케이드 롬 zip(또는 롬 파일 여러 개)을 여기에 끌어 놓거나 눌러서 고르세요

파일 이름은 달라도 됩니다 (크기와 CRC32 로 알아봅니다). zip 안의 zip 도 엽니다.

    실행

    openMSX V9968 판, 기종 Panasonic_FS-A1ST_V9968 (터보 R + V9968), 롬 형식 KonamiSCC (1MB):
    openmsx -machine Panasonic_FS-A1ST_V9968 -cart wbml_v9968_0.9.40.rom -romtype KonamiSCC

    openMSX V9968 판 설정 파일 (share/machines/, 카트는 share/extensions/ 에 넣음):

      FS-A1ST_V9968 은 V9968 포크에 들어 있는 파일이고, FS-A1GT_V9968 은 같은 포크의 FS-A1GT 에 ST 판과 같은 변경(VDP V9968, 포트 98h–9Ch)을 한 것입니다. V9968 카트(HRA_V9968, 포트 88h–8Ch)도 같은 롬을 씁니다: 부팅 때 88h 에 VDP 가 있는지 시험해 스스로 정합니다 (v0.9.28 부터). openMSX 예: -machine Panasonic_FS-A1GT -ext HRA_V9968, 화면은 부팅 뒤 videosource 를 V9968 로.

      조작
      • 이동: 커서 키 / 조이스틱 (위: 문 들어가기)
      • 공격: SPACE, Z, 트리거 A · 점프: X, M, 트리거 B
      • 코인: 5, F1, SELECT, 트리거 B · 1P 시작: 1, F5, RETURN, 트리거 A
        조이스틱 버튼의 코인·시작은 게임 밖(타이틀·데모, 시작 대기, 이어하기 화면)에서만. 플레이 중에는 공격·점프.
