원더보이 몬스터랜드 MSX V9990 패처 m27

아케이드 롬(한글 패치 v0.21·v0.10, 일본판 wbml·wbmld, 영문 wbmlb 중 하나, 어느 것인지 자동으로 알아봄)을 넣으면 MSX 터보 R + GFX9000(V9990) 용 롬을 만듭니다. 파일은 브라우저 안에서만 처리되고 어디에도 올라가지 않습니다.

아케이드 롬 zip(또는 롬 파일 여러 개)을 여기에 끌어 놓거나 눌러서 고르세요

파일 이름은 달라도 됩니다 (크기와 CRC32 로 알아봅니다). zip 안의 zip 도 엽니다. 영문 wbmlb 를 부모 롬 없이 받은 경우(wbml.01 등 6개)는 일본판 wbml zip 도 함께 넣으세요.

    다시 내려받기

    실행

    openMSX, 기종 Panasonic_FS-A1ST (터보 R) + 확장 gfx9000, 롬 형식 KonamiSCC (512KB):
    openmsx -machine Panasonic_FS-A1ST -ext gfx9000 -cart wbml_v9990_m27.rom -romtype KonamiSCC

    화면: openMSX 콘솔(F10)에서 set videosource GFX9000 (openMSX 는 처음에 MSX VDP 화면을 보여 줍니다).

    필요한 것: MSX 터보 R (R800), GFX9000 (V9990, 포트 60h–6Fh), 카트리지 매퍼 Konami SCC. FS-A1GT 도 됩니다 (-machine Panasonic_FS-A1GT).

    조작
    • 이동: 커서 키 / 조이스틱 (위: 문 들어가기)
    • 공격: SPACE, Z, 트리거 A · 점프: X, M, 트리거 B
    • 코인: 5, F1, SELECT, 트리거 B · 1P 시작: 1, F5, RETURN, 트리거 A
      조이스틱 버튼의 코인·시작은 게임 밖(타이틀·데모, 시작 대기, 이어하기 화면)에서만. 플레이 중에는 공격·점프.
    • F2: 옵션 메뉴 (DIP 스위치, 타이틀·데모에서)
