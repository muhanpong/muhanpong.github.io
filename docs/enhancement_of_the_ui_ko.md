# MSX2 MV2 웹 인코더 - UI 개선 계획

## 개요
이 문서는 `encoder.html` 인터페이스에 고급 미리보기, 크롭(자르기), 모니터링 및 정밀한 인코딩 구간 선택 기능을 도입하기 위한 아키텍처 계획을 간략하게 설명합니다. 인코딩 전과 도중에 사용자에게 뛰어난 상호작용성, 반응성, 그리고 직관적인 정보를 제공하는 것을 목표로 합니다.

## 1단계: 반응형 디자인 및 도움말 시스템
*   **모바일 맞춤:** 픽셀화된 렌더링을 유지하면서 모바일 기기에서도 알맞게 크기가 조절되도록 미리보기 `<canvas>`의 CSS에 `max-width: 100%`, `height: auto`, 동적 `aspect-ratio`를 추가합니다.
*   **정보(Info) 아이콘:** "MSX2 MV2 Web Encoder" 메인 타이틀 옆에 SVG 형태의 정보 아이콘(`ⓘ`)을 추가합니다.
*   **툴팁:** 가벼운 자바스크립트 툴팁 시스템을 구현합니다. 사용자가 정보 아이콘을 클릭/터치한 후 라벨(예: "Quantizer Algorithm", "Dither Strength")에 마우스를 올리거나 터치하면 해당 설정의 목적을 설명하는 툴팁이 팝업으로 나타납니다.

## 2단계: 원본 미디어 미리보기, 탐색 및 구간 선택
*   **숨겨진 비디오 요소:** DOM에 사용자가 선택한 파일을 로드할 보이지 않는 `<video>` 요소를 관리합니다.
*   **파일 선택 동작:** 사용자가 `#videoInput`을 통해 파일을 선택하거나 **`previewCanvas` 영역에 파일을 드래그 앤 드롭(Drag & Drop)하면**, 숨겨진 비디오 요소에 파일을 로드하고 첫 프레임을 `previewCanvas`에 그립니다.
*   **고급 탐색 슬라이더 및 구간 선택:** 정확한 인코딩 구간을 탐색하고 지정하기 위해 캔버스 하단에 대화형 타임라인을 도입합니다.
    *   **시간 입력 UI:** 매우 정밀한 시작 및 종료 시간 설정을 위해 `[hh]:[mm]:[ss].[SSS]` 형식의 텍스트/숫자 입력 필드를 추가합니다.
    *   **드래그 가능한 마커:** 슬라이더 트랙에 시작 및 종료 시점을 나타내는 시각적 마커를 추가합니다. 사용자는 이 마커들을 마우스로 잡고 개별적으로 드래그할 수 있습니다.
    *   **마커 위치 제한 규칙:** 시작 마커가 종료 마커를 지나치거나, 종료 마커가 시작 마커보다 앞서지 못하도록 제약 로직을 강제합니다 (서로 교차할 수 없음).
    *   **클릭-앤-드래그(Click-and-Drag) 앵커 로직:** 마커가 아닌 슬라이더 트랙의 빈 공간을 클릭(마우스 다운)하면 기준점(Anchor)이 설정됩니다.
        *   기준점 셋팅 후 마우스를 왼쪽으로 드래그할 때: 기준점은 '종료 마커'가 되고 현재 마우스 위치가 '시작 마커'가 됩니다.
        *   기준점 셋팅 후 마우스를 오른쪽으로 드래그할 때: 기준점은 '시작 마커'가 되고 현재 마우스 위치가 '종료 마커'가 됩니다.
    *   **양방향 동기화:** 마커를 드래그하면 `[hh]:[mm]:[ss].[SSS]` 입력 폼의 값이 자동으로 업데이트되며, 입력 폼에 직접 숫자를 타이핑하면 슬라이더 위의 시각적 마커 위치가 즉시 반영됩니다.
*   **상호작용성:** 슬라이더를 스크러빙(Scrubbing)하면 숨겨진 비디오의 `currentTime`이 동기화되며, 실시간으로 해당 프레임을 `previewCanvas`에 그려주어 원본 미디어의 정확한 프레임을 확인할 수 있습니다.

## 3단계: 화면 비율 및 대화형 타겟 윈도우
*   **비율 선택 라디오 버튼:** 목표 인코딩 비율인 **[ 5:3 ]** (MSX 표준) 또는 **[ 4:3 ]** 중 하나를 선택할 수 있는 버튼을 추가합니다.
*   **타겟 오버레이 드로잉:** 미리보기 모드일 때, 선택된 'Aspect Mode(비율 모드)'에 따라 최종 인코딩될 영역을 표시하는 시각적 오버레이(예: 반투명 테두리 또는 점선 윤곽)를 `previewCanvas` 위에 그립니다.
    *   *Pad 모드:* 오버레이가 레터박스 또는 필러박스 영역을 나타냅니다.
    *   *Force 모드:* 오버레이가 캔버스 전체를 덮습니다 (영상이 늘어나거나 찌그러짐을 의미).
    *   *Crop 모드:* 오버레이가 선택한 목표 비율(5:3 또는 4:3)을 유지하면서 원본 이미지 중 어느 부분이 인코딩될지 지정해 줍니다.
*   **대화형 크롭 영역 지정 (드래그):** 
    *   캔버스에 마우스/터치 이벤트 리스너를 연결합니다.
    *   'Crop 모드'가 선택된 경우, 캔버스 위에 그려진 타겟 윈도우를 드래그하여 자를 영역을 물리적으로 이동시킬 수 있습니다.
    *   이 드래그 동작은 입력 폼의 "Crop Left Offset (%)" 및 "Crop Up Offset (%)" 값을 실시간으로 계산하고 업데이트합니다.

## 4단계: 인코딩 전 상태 잠금
*   **UI 동결:** "Start Encoding(인코딩 시작)"을 클릭하면 설정이 변경되는 것을 막기 위해 모든 설정 입력 요소(`input`, `select`, 비율 라디오 버튼)와 탐색 슬라이더의 마커들을 `disabled = true` 처리하여 회색으로 비활성화합니다.
*   **모드 전환:** 캔버스의 내부 상태가 "미리보기 모드"에서 "인코딩 모니터링 모드"로 전환됩니다.

## 5단계: 3분할 화면 인코딩 모니터 (Tri-State)
*   **다중 상태 렌더링 요구사항:** 인코딩 도중 모니터링 기능을 구현하려면 시스템이 3가지 버전의 프레임에 접근해야 합니다:
    1.  `Source`: 크기가 조절된 원본 프레임.
    2.  `VRAM Packed`: 최종적으로 MSX2 제약이 적용된 이미지 (기본 MV2 룩).
    3.  `Raw Dithered`: VRAM의 블록당 색상 수 제한(color clash)이 적용되기 *전*의 디더링된 이미지.
*   **대화형 분할 경계선 (Splitters):** 캔버스 위에 보이지 않는 수직 경계선(손잡이) 두 개를 배치합니다:
    *   **왼쪽 경계선:** 이 선을 마우스로 잡고 오른쪽으로 드래그하면, 선의 왼쪽 공간에는 `Source` 미디어가 드러나고 오른쪽은 여전히 `VRAM Packed`가 표시됩니다.
    *   **오른쪽 경계선:** 이 선을 마우스로 잡고 왼쪽으로 드래그하면, 선의 오른쪽 공간에는 `Raw Dithered` 미디어가 드러나고 왼쪽은 여전히 `VRAM Packed`가 표시됩니다.
*   **렌더링 로직 (모니터 모드):**
    *   캔버스를 지웁니다.
    *   $X=0$ 부터 $X=왼쪽 경계선$ 영역에 `Source` 이미지를 그립니다.
    *   $X=왼쪽 경계선$ 부터 $X=오른쪽 경계선$ 영역에 `VRAM Packed` 이미지를 그립니다.
    *   $X=오른쪽 경계선$ 부터 $X=너비$ 영역에 `Raw Dithered` 이미지를 그립니다.
    *   경계선 위치에 수직선(예: 뚜렷한 단색 선)을 그려 뷰의 분할을 명확히 시각화합니다.
    *   *기본 상태:* 왼쪽 경계선은 $X=0$, 오른쪽 경계선은 $X=너비$ 지점에 위치하므로, 기본적으로 화면 전체에 `VRAM Packed` 이미지만 보입니다.

## 6단계: 조기 중단 및 부분 결과물 다운로드
*   **중단 버튼:** 인코딩이 시작되면 "Start Encoding(인코딩 시작)" 버튼이 "Stop Encoding(인코딩 중지)" 버튼으로 형태가 바뀝니다.
*   **안전한 인터럽트:** "Stop Encoding" 버튼을 누르면 즉시 인코딩 루프 실행을 멈춥니다.
*   **부분 인코딩 파일 병합:** 시스템은 사용자가 중지 버튼을 누른 바로 그 시점까지 처리 완료된 수만큼의 프레임 정보와 MP3 오디오 청크들을 취합하여 멀티플렉서를 안전하게 닫습니다. 이후 곧바로 짤린 길이만큼의 `.mv2` 및 `.rgb` 파일 다운로드가 시작됩니다.
